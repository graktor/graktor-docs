# Kí ni Graktor?

Graktor (tí Zendoria Ventures ṣe) jẹ́ pẹpẹ fún títa ọjà (POS), ìṣàkóso ọjà-ìní, àjọṣe pẹ̀lú àwọn
oníbàárà (CRM), àti owó fún àwọn oníṣòwò tí ń ta ọjà ní Nàìjíríà — yálà ilé-ìtajà kan ṣoṣo tàbí
ọ̀pọ̀lọpọ̀ ẹ̀ka, lórí àkáǹtì kan ṣoṣo.

Ó ń ṣiṣẹ́ gẹ́gẹ́ bí:

- **Ìwé-ìṣàkóso lórí ayélujára**, tí a lè lò láti ọwọ́ ẹ̀rọ aṣàwákiri èyíkéyìí.
- **App tí a lè gbé sórí Windows**.
- **App Android**.
- **Ilé-ìtajà ẹlẹ́gbẹ́ lórí ayélujára** fún oníṣòwò kọ̀ọ̀kan, àti ọjà-tàjà pínpín kan tí ó ń ṣe
  àtòjọ ọjà láti ọ̀pọ̀lọpọ̀ oníṣòwò ní ẹ̀ẹ̀kan náà.

Oníṣòwò kọ̀ọ̀kan yàn **àwòṣe** kan nígbà tí wọ́n bá forúkọsílẹ̀ — ilé-ìtajà oúnjẹ, ilé-ìtajà
oògùn, ilé-ìtajà aṣọ, ilé-ìtajà irinṣẹ́, ẹ̀rọ oníná mọ̀nà-mọ́ná, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ — tí ó ń ṣètò
àwọn ìpìlẹ̀ tí ó bá a mu: ẹ̀ka ọjà, ìwọ̀n, àti àwọn apá-ìṣẹ́ tí a ó ti ṣí sílẹ̀ láti ìbẹ̀rẹ̀pẹ̀pẹ̀.
Kò sí ohunkóhun tí kò lè yí padà; a lè ṣí tàbí pa apá-ìṣẹ́ èyíkéyìí nígbàkigbà láti orí Ìtòsọ̀rọ̀.

## Fún ta ni Graktor

- Ilé-ìtajà kan ṣoṣo tí ń fi ìkọ̀wé-ìwé tàbí ìwé-àkọsílẹ̀ sílẹ̀.
- Oníṣòwò tí ó ní ọ̀pọ̀lọpọ̀ ẹ̀ka tí ó nílò àkáǹtì kan ṣoṣo fún gbogbo àwọn ẹ̀ka rẹ̀, pẹ̀lú ọjà àti
  títà tí a lè rí láti àárín gbùngbùn.
- Oníṣòwò tí ó fẹ́ ilé-ìtajà lórí ayélujára tí ó ń bá ọjà inú ilé-ìtajà mu láìṣe àtúnkọ ohunkóhun.
