# Cash services (POS agent)

*Plan/template-gated — feature key `cashServices`.*

POS-agent-style cash services — Withdrawal, Deposit, Transfer — run as their own transaction type,
separate from selling stock. Any signed-in role can quote a fee and record one (it's a till-side
action, same as ringing up a sale); Admin/Manager see the transaction history and report.
