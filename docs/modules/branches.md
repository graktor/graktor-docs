# Branches

One login covers every branch a business has — stock, sales, and staff are all visible centrally,
per branch.

- Admin can create/edit/remove branches.
- Each branch can **override its template**, so one branch of a multi-branch business can run a
  genuinely different kind of shop (e.g. a pharmacy branch under the same login as a boutique
  branch) without needing a second account.
- [Add-ons](../billing-and-plans.md#add-ons) marked branch-scopable (like cameras) can be switched
  on for one branch only, rather than the whole business.
- [Retail pack](./retail-pack.md) branch transfers move stock between branches with a record of
  the move.
