# Calendar & booking

*Service-business tool.*

Appointment capacity for a staff member or a named resource -- a stylist's own calendar, a spa
room, a massage bed, a rented vehicle. Booking a resource for an overlapping time that's already
taken is refused outright; two different resources (two different rooms, two different staff) can
be booked for the exact same time with no conflict.

- A booking can optionally link to a [ticket](./tickets.md).
- Cancelling a booking requires a reason, kept on the record, and frees the slot immediately for
  someone else.

## Honesty note

No recurring-booking engine -- a weekly repeat booking is created as individual rows, one at a
time, not generated automatically into the future.
