# Pharmacy pack

*Template module — feature key `pharmacy`.*

- Stock held in **dated batches** rather than one running total — selling always takes from the
  batch expiring soonest first, and an expired batch is never sold.
- **Expiry reports** — what's already expired and what's expiring soon, with their value at cost.
- **Write-offs** for expired/damaged batches, with a reason.
- **Prescription-only and controlled medicines** — a dispensing log recording patient name,
  prescriber, prescription reference, and whether the item was a controlled medicine.
- **Batch tracing** — for a recall, trace exactly which sales a given batch went into (customer
  name/phone where known).
