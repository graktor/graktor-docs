# Retail pack

*Template module — feature key `retail`.*

- **Barcode scanning at the till** — scan a product's barcode to add it straight to the cart.
- **Per-product tax rate** — set a tax percentage on any product; it applies automatically at
  sale time.
- **Branch transfers** — move stock from one branch to another, with a record of who moved what,
  when, and why.
