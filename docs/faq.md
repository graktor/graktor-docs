# FAQ

### Can I change my template after signing up?

Yes. A template only sets starting defaults — every module it turns on can be switched off, and
anything it didn't turn on can be switched on, from Settings at any time.

### Can different branches run different kinds of shop?

Yes — any branch can override the business's own template, and branch-scopable add-ons (like
cameras) can be turned on for one branch only.

### Does the till work without internet?

Yes. Products and customers are cached locally so a cashier can keep selling; everything syncs
once the connection returns.

### What happens to my data if I stop paying?

Not covered in this version of the docs yet — ask directly for the current policy.

### My camera feed isn't showing — what do I check first?

In order: is the camera itself powered on and reachable on the shop network, is its RTSP channel
set correctly, and is the Camera Bridge's pairing still valid. See
[Cameras & the Camera Bridge](./modules/cameras.md) for the full checklist.
